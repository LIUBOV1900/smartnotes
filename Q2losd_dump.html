🧠
Словарь Python
data = {...} (в оперативной памяти)
data = {
  "О планетах": {
    "текст": "...",
    "теги": [...]
  }
}
📥 Загрузка (Чтение) LOAD
import json

# Открываем файл для чтения
with open("notes_data.json", 
         "r", encoding="utf-8") as file:
    
    # JSON → Словарь Python
    data = json.load(file)
📤 Выгрузка (Запись) DUMP
import json

# Открываем файл для записи
with open("notes_data.json", 
         "w", encoding="utf-8") as file:
    
    # Словарь Python → JSON
    json.dump(data, file, 
              ensure_ascii=False,
              sort_keys=True)

💡 Структура данных в JSON файле и словаре Python идентична!

json.load() преобразует файл в словарь • json.dump() сохраняет словарь в файл
