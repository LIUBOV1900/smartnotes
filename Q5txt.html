📁 Новая структура хранения

Главный принцип: каждая заметка хранится в отдельном TXT файле с номером

📄 2.txt

Структура одного файла:

  • Строка 1 — название заметки
  • Строка 2 — текст заметки
  • Строка 3 — теги через пробел

Преимущество TXT: заметки можно создавать и редактировать без приложения — на телефоне, в блокноте, просто скопировав файл в папку проекта

📥 Чтение данных: алгоритм

Нужно прочитать все файлы 0.txt, 1.txt, 2.txt... пока они существуют

num = 0
→
Открыть num.txt
→
Прочитать в note
→
Добавить в notes
↑
Цикл while True
→
Файл не найден?
→
break

Ключевая идея: используем try/except IOError — если файл не открывается, значит все заметки прочитаны, выходим из цикла

💻 Чтение данных: код

notes = []
num_name = 0

while True:
    filename = str(num_name) + ".txt"
    try:
        with open(filename, "r") as file:
            note = []
            for line in file:
                line = line.strip()  # убираем '\n'
                note.append(line)
            
            # note[2] — строка с тегами, разделяем на список
            note[2] = note[2].split()
            notes.append(note)
        
        num_name += 1
    except IOError:
        break  # файла нет — все заметки прочитаны

Важно: после чтения note — это список [название, текст, [теги]], а не словарь!

➕ Функция add_note() — создание заметки

JSON версия 
def add_note():
    note_name, ok = ...
    if ok and note_name:
        notes[note_name] = {
            "текст": "",
            "теги": []
        }
        list_notes.addItem(note_name)
        # Сохраняем весь JSON
        with open("notes.json", "w") as f:
            json.dump(notes, f)
TXT версия 
def add_note():
    note_name, ok = ...
    if ok and note_name:
        note = [note_name, '', []]
        notes.append(note)
        list_notes.addItem(note_name)
        
        # Записываем в НОВЫЙ файл
        filename = str(len(notes)-1) + ".txt"
        with open(filename, "w") as file:
            file.write(note[0] + '\n')

Изменение: вместо обновления одного JSON файла создаём новый TXT файл с номером len(notes)-1

def save_note():

        key = list_notes.selectedItems()[0].text()
        i = 0
        
        for note in notes:
            if note[0] == key:
                # Нашли нужную заметку — обновляем текст
                note[1] = field_text.toPlainText()
                
                # Записываем в её файл

Ключевое отличие: вместо json.dump() пишем файл построчно вручную. Перезаписываем только файл нужной заметки

🗑️ Функция del_note() — удаление заметки

Удаление заметки в TXT-версии — самая сложная операция. Почему?

Проблема: нумерация файлов

Если удалить, например, 1.txt, то 2.txt должен стать новым 1.txt, 3.txt → 2.txt и т.д.

Пример: удаляем заметку "О чёрных дырах" (файл 1.txt)

До удаления:
0.txt
О планетах
1.txt
О чёрных дырах
2.txt
О галактиках
3.txt
О квантовой...
После удаления (файлы переименованы):
0.txt
О планетах
1.txt
О галактиках
2.txt
О квантовой...

Главная сложность: нужно не просто удалить файл, но и перезаписать все оставшиеся файлы с новыми номерами

def del_note():
    if list_notes.selectedItems():

⚠️ Сложно: перебор + перезапись ВСЕХ файлов

Главное отличие: в JSON — одно действие удаления. В TXT — нужно перенумеровать все файлы, чтобы не было "дырок" в нумерации

💻 del_note(): полный код TXT версии

def del_note():
    if list_notes.selectedItems():
        key = list_notes.selectedItems()[0].text()
        
        # 1. Удаляем заметку из списка notes
        for note in notes:
            if note[0] == key:
                notes.remove(note)
                break
        
        # 2. Очищаем виджеты интерфейса
        list_notes.clear()
        field_text.clear()
        list_notes.addItems(notes)  # обновляем список
        
        # 3. ПЕРЕЗАПИСЫВАЕМ ВСЕ ФАЙЛЫ с новыми номерами!
        for i in range(len(notes)):
            filename = str(i) + ".txt"
            with open(filename, "w") as file:
                file.write(notes[i][0] + '\n')   # название
                file.write(notes[i][1] + '\n')   # текст
                for tag in notes[i][2]:
                    file.write(tag + ' ')         # теги
                file.write('\n')
