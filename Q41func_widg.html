📋 QListWidget — виджет списка

QListWidget — это виджет для отображения списка элементов (строк). В нашем приложении используется для:

list_notes

Список заметок

Показывает названия всех заметок. Пользователь может выбрать одну из них.

list_tags

Список тегов

Показывает теги выбранной заметки. Можно выбрать тег для удаления.

# Создание виджетов списков
list_notes = QListWidget()  # Список заметок
list_tags = QListWidget()   # Список тегов

Важно: QListWidget хранит элементы как строки и позволяет работать с ними: добавлять, удалять, выбирать.

➕ Метод addItem() — добавить один элемент

list_notes.addItem("Текст элемента")

Добавляет один элемент (строку) в конец списка

Пример 1 
# Добавление названия заметки
note_name = "О планетах"
list_notes.addItem(note_name)

# В списке появится:
# • О планетах
Пример 2 
# Добавление одного тега
tag = "Марс"
list_tags.addItem(tag)

# В списке тегов появится:
# • Марс

Используется в: add_note() — добавляет название новой заметки в список

➕➕ Метод addItems() — добавить несколько элементов

list_notes.addItems(список_строк)

Добавляет несколько элементов (список строк) в список

# Пример 1: Добавление всех названий заметок при запуске
notes = {"О планетах": {...}, "О чёрных дырах": {...}}
list_notes.addItems(notes)

# Когда передаёте словарь, addItems берёт его ключи!
# В списке появятся:
# • О планетах
# • О чёрных дырах

# Пример 2: Добавление списка тегов
tags = ["Марс", "гипотезы", "космос"]
list_tags.addItems(tags)

# В списке появятся:
# • Марс
# • гипотезы
# • космос

Важно: При передаче словаря в addItems(), Python автоматически использует только ключи словаря!

🗑️ Метод clear() — очистить список

list_tags.clear()

Полностью удаляет все элементы из списка

Зачем нужно?

Перед добавлением новых элементов нужно очистить старые, чтобы не было дублирования!

Пример 
# При выборе другой заметки:
list_tags.clear()  # Удалить старые теги
list_tags.addItems(notes[key]["теги"])  # Добавить новые
# Пример из функции show_note():
def show_note():
    key = list_notes.selectedItems()[0].text()
    field_text.setText(notes[key]["текст"])
    
    list_tags.clear()  # Очищаем список тегов!
    list_tags.addItems(notes[key]["теги"])  # Добавляем теги новой заметки

Без clear() теги от разных заметок будут накапливаться в списке!

☑️ Метод selectedItems() — получить выбранные элементы

list_notes.selectedItems()

Возвращает список выбранных элементов (объектов QListWidgetItem)

# selectedItems() возвращает СПИСОК выбранных элементов
selected = list_notes.selectedItems()

# Если выбран один элемент:
print(len(selected))  # >>> 1

# Чтобы получить текст первого выбранного элемента:
name = list_notes.selectedItems()[0].text()
print(name)  # >>> "О планетах"
[0]

Берём первый элемент из списка выбранных (индекс 0)

.text()

Получаем текст (название) этого элемента

Используется в: show_note(), save_note(), del_note(), add_tag(), del_tag() — везде, где нужно узнать, какую заметку выбрал пользователь

👆 Сигнал itemClicked — реакция на клик

list_notes.itemClicked.connect(function)

Сигнал (событие), который срабатывает при клике на элемент списка

# Подключение обработчика события
list_notes.itemClicked.connect(show_note)

# Теперь при клике на любую заметку в списке
# автоматически вызывается функция show_note()
Как работает?
  1. Пользователь кликает на название заметки
  2. Срабатывает сигнал itemClicked
  3. Вызывается функция show_note()
  4. Функция отображает текст и теги заметки
Аналогия

Это как обработчик событий в JavaScript: onclick или addEventListener('click', ...)

Это не метод, а сигнал! Он не выполняет действия сам, а уведомляет программу о событии.

📝 QTextEdit — многострочное текстовое поле

QTextEdit — виджет для ввода и отображения многострочного текста. В нашем приложении показывает текст заметки. 

# Создание виджета
field_text = QTextEdit()

Основные методы:

setText("Текст")

Установить текст в поле

field_text.setText(notes[key]["текст"])
toPlainText()

Получить текст из поля (как строку)

text = field_text.toPlainText()
notes[key]["текст"] = text

Используется в: show_note() (setText), save_note() (toPlainText)

✏️ QLineEdit — однострочное поле ввода

QLineEdit — виджет для ввода одной строки текста. В нашем приложении используется для ввода нового тега. 

# Создание виджета
field_tag = QLineEdit()
field_tag.setPlaceholderText("Введите тег...")

Основные методы:

text()

Получить текст из поля

tag = field_tag.text()
clear()

Очистить поле

field_tag.clear()
setPlaceholderText()

Установить текст-подсказку (серый текст, когда поле пустое)

field_tag.setPlaceholderText("Введите тег...")

Используется в: add_tag() (text, clear), search_tag() (text, clear)

🔘 QPushButton — кнопка

QPushButton — виджет кнопки. В нашем приложении 7 кнопок для различных действий. 

# Создание кнопок
button_note_create = QPushButton("Создать заметку")
button_tag_search = QPushButton("Искать заметки по тегу")

Основные методы:

clicked.connect()

Подключить функцию к событию клика

button_note_create.clicked.connect(add_note)
text()

Получить текст кнопки

btn_text = button_tag_search.text()
setText()

Изменить текст кнопки

button_tag_search.setText("Сбросить поиск")

Все кнопки в приложении: button_note_create, button_note_del, button_note_save, button_tag_add, button_tag_del, button_tag_search

💬 QInputDialog — диалоговое окно ввода

QInputDialog — стандартное диалоговое окно для ввода данных. В нашем приложении используется для запроса названия новой заметки. 

def add_note():
    note_name, ok = QInputDialog.getText(
        notes_win,                    # Родительское окно
        "Добавить заметку",           # Заголовок окна
        "Название заметки: "         # Подпись поля ввода
    )
Возвращает
  • note_name — введённый текст
  • ok — True, если нажали OK; False, если отменили
Проверка 
if ok and note_name != "":
    # Создаём заметку
else:
    # Пользователь отменил ввод
    # или ввёл пустую строку

Используется только в: add_note() — для запроса названия новой заметки

🏷️ QLabel и QWidget — базовые виджеты

QLabel

Текстовая метка

Отображает неподвижный текст (заголовки, подписи)

list_notes_label = QLabel("Список заметок")
list_tags_label = QLabel("Список тегов")
QWidget

Базовое окно

Основное окно приложения, контейнер для всех виджетов

notes_win = QWidget()
notes_win.setWindowTitle("Умные заметки")
notes_win.resize(900, 600)

Основные методы QWidget:

setWindowTitle()

Установить заголовок окна

resize()

Задать размер окна (ширина, высота)

show()

Показать окно на экране

Итог: Все виджеты размещаются внутри notes_win (QWidget) с помощью лэйаутов (QVBoxLayout, QHBoxLayout)
