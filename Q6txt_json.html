Переход с JSON на TXT

Как меняется программа при смене формата хранения данных

Было

JSON файл

Готовая структура данных, словари и списки

Стало

TXT файл

Простой текст, нужна ручная обработка

Используйте стрелки ← → или кнопки внизу для навигации

📦 Как хранятся данные

JSON формат 
{
  "О планетах": {
    "текст": "Что если вода...",
    "теги": ["Марс", "гипотезы"]
  }
}

Словарь с вложенной структурой

TXT формат 
О планетах
Что если вода на Марсе это признак жизни?
---
О чёрных дырах
Сингулярность на горизонте событий...
---

Простой текст с разделителями

Важно: В TXT файле нет тегов — только название и текст заметки. Каждая заметка отделена строкой ---

📥 Загрузка данных при запуске

JSON версия 
import json

with open("notes.json", "r") as file:
    notes = json.load(file)

# notes — готовый словарь!

Одна команда — вся структура загружена

TXT версия 
notes = {}

with open("notes.txt", "r") as file:
    lines = file.readlines()

# Парсим файл построчно
i = 0
while i < len(lines):
    name = lines[i].strip()
    text = lines[i+1].strip()
    notes[name] = text
    i += 3  # Пропускаем разделитель ---

Нужно вручную разобрать каждую строку

Изменение: Вместо json.load() используем readlines() + цикл для разбора текста

    name = list_notes.selectedItems()[0].text()
    field_text.setText(notes[name])  # Просто значение

Значение — это и есть текст

💾 Функция save_note() — сохранение заметки

JSON версия 
def save_note():
    if list_notes.selectedItems():
        key = list_notes.selectedItems()[0].text()
        notes[key]["текст"] = field_text.toPlainText()
        with open("notes.json", "w") as file:
            json.dump(notes, file, 
                     ensure_ascii=False,
                     sort_keys=True)

Обновляем ключ "текст" и сохраняем JSON

TXT версия 
def save_note():
    if list_notes.selectedItems():
        key = list_notes.selectedItems()[0].text()
        notes[key] = field_text.toPlainText()
        
        with open("notes.txt", "w") as file:
            for name, text in notes.items():
                file.write(name + "\n")
                file.write(text + "\n")
                file.write("---\n")

Обновляем значение и пишем TXT построчно

Изменение: Вместо json.dump() пишем файл вручную: название → текст → разделитель ---

    if list_notes.selectedItems():

📊 Итоговое сравнение

Аспект JSON версия TXT версия
Структура данных Словарь с вложенными словарями Словарь: название → текст
Загрузка json.load(file) readlines() + цикл разбора
Сохранение json.dump(notes, file) Цикл write() с разделителями
Доступ к тексту notes[name]["текст"] notes[name]
Теги ✅ Есть (список) ❌ Нет
Сложность кода Проще (готовая структура) Сложнее (нужен парсинг)

Вывод: JSON удобнее для сложных данных, но TXT проще для понимания (можно открыть в блокноте)

✨ Что изменилось в программе

Удалено
  • Импорт библиотеки json
  • Работа с тегами (все функции)
  • Вложенная структура словаря
  • Методы json.load() и json.dump()
Добавлено
  • Ручной парсинг TXT файла при загрузке
  • Ручная запись TXT файла при сохранении
  • Разделитель --- между заметками
  • Упрощённая структура: название → текст

💡 Главная идея: TXT файл требует ручной обработки,
но зато его можно прочитать без специальных программ

Отличная работа! Теперь вы понимаете разницу между JSON и TXT подходами.
