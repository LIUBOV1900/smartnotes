Работа с JSON файлами

Структурированное хранение данных в Python

Как сохранить сложные данные (с тегами и переносами строк) так,
чтобы их было легко читать, изменять и использовать в программе?

Используйте стрелки на клавиатуре (← →) или кнопки внизу экрана

Проблема и Решение

Проблема

Нужна структура для удобного хранения сложных заметок (с текстом, тегами, переходами на новые строки).

Обычные текстовые файлы слишком тяжело читать и записывать!

Решение

Использовать JSON файлы — файлы с готовой структурой данных, которые используют программисты по всему миру.

Структура в файле и в программе будет идентична!

Что такое JSON?

JSON — это текстовый формат с готовой структурой, удобной для чтения и использования.

Структура JSON файла очень похожа на систему вложенных словарей и списков в Python.

{
  "О планетах": {
    "текст": "Что если вода на Марсе это признак жизни?",
    "теги": ["Марс", "гипотезы"]
  },
  "О чёрных дырах": {
    "текст": "Сингулярность на горизонте событий отсутствует",
    "теги": ["чёрные дыры", "факты"]
  }
}

Загрузка данных (Чтение)

Для работы используется встроенная библиотека json. Метод json.load() преобразует JSON-файл обратно в словарь Python.

import json

# Открываем файл для чтения (r)
with open("notes_data.json", "r", encoding="utf-8") as file:
    # Загружаем структуру из файла в словарь data
    data = json.load(file)

# Теперь data - это обычный словарь Python!
print(data["О планетах"]["текст"])

💡 После чтения переменная data имеет точно такую же структуру, как и сам JSON файл.

Выгрузка данных (Запись)

Метод json.dump() сохраняет словарь Python в файл. Важно: JSON файл при этом полностью перезаписывается!

import json

# Открываем файл для перезаписи (w)
with open("notes_data.json", "w", encoding="utf-8") as file:
    # Записываем словарь data в файл
    json.dump(data, file, ensure_ascii=False, sort_keys=True)

ensure_ascii=False

Позволяет записывать русские символы в читаемом виде, а не в формате Unicode-экранирования.

sort_keys=True

Автоматически сортирует главные ключи (названия заметок) по алфавиту при записи.

Создание JSON файла

Существует два способа создать файл формата .json:

Способ 1: Вручную

В папке проекта создать пустой файл и дать ему расширение .json (например, data.json).

Способ 2: Программно

При первой же записи (выгрузке) данных через json.dump() файл будет создан автоматически, если его не существовало.
