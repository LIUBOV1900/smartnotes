    notes = json.load(file)

list_notes.addItems(notes)

📋 Отображение названий заметок

Виджет QListWidget показывает список названий всех заметок.

Метод

addItems()

Принимает список строк и добавляет их как элементы списка

Что передаём

notes

Словарь заметок — при передаче в addItems() используются только ключи (названия)

# notes - это словарь:
# {"О планетах": {...}, "О чёрных дырах": {...}}

# addItems берёт только ключи словаря
list_notes.addItems(notes)

# В списке появятся:
#  • О планетах
#  • О чёрных дырах

💡 Когда вы передаёте словарь в addItems(), Python автоматически использует его ключи как названия элементов списка.

👆 Что происходит при нажатии на название?

Когда пользователь кликает на название заметки в списке, программа должна:

Действие 1

Получить название выбранной заметки

Действие 2

Показать текст заметки в поле QTextEdit

Действие 3

Показать теги заметки в списке тегов

Обработчик события: Все эти действия выполняет функция show_note(), которая вызывается при клике на элемент списка.

# Подключаем функцию-обработчик к событию клика
list_notes.itemClicked.connect(show_note)

🔍 Шаг 1: Получение названия заметки

Первым делом нужно узнать, какую именно заметку выбрал пользователь.

def show_note():
    name = list_notes.selectedItems()[0].text()
Метод

selectedItems()

Возвращает список выбранных элементов в QListWidget

[0].text()

Берём первый элемент

Так как выбран один элемент, берём его под индексом [0] и получаем текст через .text()

📌 В переменной name теперь хранится строка, например: "О планетах"

📝 Шаг 2: Отображение текста заметки

Теперь нужно показать текст выбранной заметки в поле QTextEdit.

def show_note():
    name = list_notes.selectedItems()[0].text()
    field_text.setText(notes[name]["текст"])
Разбор выражения

notes[name] — получаем словарь с данными заметки по её названию

["текст"] — из этого словаря берём значение по ключу "текст"

setText() — устанавливаем этот текст в поле QTextEdit

# Пример работы:
# name = "О планетах"
# notes["О планетах"] = {"текст": "Что если...", "теги": [...]}
# notes["О планетах"]["текст"] = "Что если вода на Марсе..."

🏷️ Шаг 3: Отображение тегов заметки

После текста нужно показать теги выбранной заметки в отдельном списке.

def show_note():
    name = list_notes.selectedItems()[0].text()
    field_text.setText(notes[name]["текст"])
    
    list_tags.clear()
    list_tags.addItems(notes[name]["теги"])
clear()

Очистка списка

Сначала удаляем все старые теги, чтобы не было наложения от предыдущей заметки

addItems()

Добавление новых

Затем добавляем теги текущей заметки из списка notes[name]["теги"]

⚠️ Важно: Если не вызвать clear(), теги от разных заметок будут накапливаться в списке!

✨ Полный код функции show_note()

def show_note():
    # 1. Получаем название выбранной заметки
    name = list_notes.selectedItems()[0].text()
    
    # 2. Отображаем текст заметки в поле QTextEdit
    field_text.setText(notes[name]["текст"])
    
    # 3. Очищаем список тегов от предыдущих значений
    list_tags.clear()
    
    # 4. Добавляем теги текущей заметки
    list_tags.addItems(notes[name]["теги"])

Логика работы:

  • Пользователь кликает на название → срабатывает show_note()
  • Программа узнаёт название → достаёт данные из словаря notes
  • Текст и теги отображаются в соответствующих виджетах

  • Загружаем в словарь notes
  • Показываем названия через addItems()
При клике

Обработка выбора

  • Получаем название через selectedItems()[0].text()
  • Показываем текст через setText()
  • Обновляем теги через clear() + addItems()
